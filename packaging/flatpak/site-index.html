MousePods – Flatpak repo

Fork of MousePods by Matteo Gaudioso, with a desktop app, game profiles and head tracking for Proton games: github.com/henningnorden/mousepods.

Install

Stable (release versions): open MousePods.flatpakref with Bazaar (Bazzite), Discover or GNOME Software, or run:

flatpak install --user https://henningnorden.github.io/mousepods/MousePods.flatpakref

Test (every change on main, may break): MousePods-test.flatpakref

flatpak install --user https://henningnorden.github.io/mousepods/MousePods-test.flatpakref

Updates then come with flatpak update or through Discover. The repo is signed. Settings and calibration are shared between both channels.
